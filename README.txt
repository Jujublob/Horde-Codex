
RECHERCHE WEB (optionnel) :
- Pour que l'IA puisse faire des recherches web, crée un compte gratuit sur https://tavily.com et récupère ta clé API.
- Définis-la avec : export SEARCH_API_KEY='ta_cle_ici'
- Sans cette clé, la recherche web affichera simplement une erreur ; le reste du programme fonctionne normalement.
